# TB Plan — Хичээл

Компанийн сайтад `/hicheel/` хаягаар 19 хичээл, Google нэвтрэлт, банкны шилжүүлгийн захиалга, админы баталгаажуулалт, үзэх эрх, хувийн дасгал/асуулт, ахиц хадгалах хэсэг нэмсэн өөрчлөлт.

Энэ хувилбар **Cloudflare Workers Free + D1 Free + Workers Static Assets** ашиглахаар бэлтгэгдсэн. Сервер нь MP4 хүсэлт бүрд нэвтрэлт болон үзэх эрх шалгана. Үнэ зарлаагүй, бүртгэл хаалттай; бодит данс, үүлэн сан, домэйн тохируулга хийгдээгүй.

Үндсэн нүүрийн хоёр цэсэнд «Хичээл» холбоос нэмсэн. Одоо байгаа хуудас, зураг, бичлэгийн замыг хадгалсан. Төлбөртэй хичээлийн бүтэн эх, MP4, дуу, дасгал, хувийн бүртгэлийн аудит Git-д орохгүй.

## Локал шалгалт

Node.js 24 шаардлагатай. Wrangler 4.165.0 lockfile-д тогтоосон.

```sh
npm ci
npm run check
npm test
npm run build
```

Sparse checkout ашиглаж байгаа бол эх сайтын зураг, бичлэгийг бүрэн татах хүртэл `build` зогсоно. Зөвхөн локал кодын харагдац шалгах үед:

```sh
ALLOW_SPARSE_PREVIEW=1 npm run build
```

Энэ нь бүтэн сайт эсвэл хичээлийн бичлэг бэлэн гэсэн үг биш. Бодит нээлтийн build-д бүх эх медиа болон 19 хичээлийн private manifest хэрэгтэй.

## Нэмэлт сарын төлбөргүй хүрээ

Workers болон D1 **Free** түвшинд үлдэнэ; R2, Stream, төлбөртэй Supabase, QPay API ашиглахгүй. Free хязгаар дуусвал ажиллагаа түр зогсоно. Код автоматаар paid түвшин рүү шилжүүлэхгүй. `FREE_MODE=1` нь кодын хамгаалалт болохоос аккаунтын төлбөрийн төлөвийг тогтоохгүй; Cloudflare дээр Free гэдгийг тусад нь шалгана.

Энэ Git өөрчлөлт үүлэн үйлчилгээ үүсгэх, төлбөр хийх, DNS солих, production байршуулалт хийх автомат workflow агуулахгүй.
